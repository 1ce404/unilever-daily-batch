# tests/
> L2 | 父级: ../CLAUDE.md

本模块以离线测试保护生产状态与返工边界。
状态测试保护批量条目引用与新版复审受理数量。
分享测试保护写前备份、旧链接与新版对象回读。
用户复核交付不增加 AI 审核通过数。
测试不把平台内容审核替换为结构校验。

成员清单
- test_ai_tags.py: AI 标签分类、场景覆盖与「AI-MMDD-素材方向」命名；旧计划沿用旧标签。
- test_aigc_gen.py: 生成计划、独立素材绑定与卡审库（文案分级、上下文短词、画面提醒）回归。
- test_aigc_materials.py: 素材组去重、源区间与播放边界。
- test_opener_refresh.py: 默认音轨不可变；显式授权只改音量；音频来源与字幕不变；拒绝非法音量与角标越界。
- test_overview.py: 总排期日期、跨周与品线解析。
- test_footage_qc.py: 声音与时长不可变；签名刷新只认同域同对象；备份续跑不重复写入或渲染；新版审核固定输出与受理数量且不重试不确定受理；重渲只允许封面元数据更新；旧窗口免重复探测，新来源、起点、速率与帧率仍须实测；拒绝非法源帧、空隙、单帧、非有限速率与超源。
- test_resume_batch.py: 授权、源时长与原脚本门禁；拒绝重复追加和不确定重试；只读审核禁止写请求。
- test_batch_completion.py: 九组补齐授权、条数、脚本文字、不确定请求防重复；正面干净、干爽与时间顺序误拦回归。
- test_delivery_share.py: 单条兼容、十条合并与两账号九十条交付；配额、最新审核、对象顺序、完整成员及不确定写入回归；用户检查须有原话，仍拒绝错产品、错脚本、旧输出与并发变化；空剪辑产品仍核对脚本产品；十条合并只建独立分享。
- test_qc_gates.py: 不双倍产、单条合格素材固定、dry-run 收据门禁、poll 与分享按 brief 限定写入、分享视频必填 cut_id，线上重渲不替换已审核输出、标签随机与显式指定、开头切片复用、编号选片及手动换后来源、产品名与成分分段、形态疑问须由下一句完整产品即时回答、每段必须写画面；去花字保留转场，禁用源片实测时长与时间轴不变。
- test_flow_gates.py: 用户 11-22 流程顺序与提速：默认 demo、AIGC 素材人审先于 demo、首轮只出 1 条、poll 并发且不越 brief；并发建脚本、重复开头不触发换片或草稿写入、闸门不过不渲染、尾部轮询加快。
- test_effects.py: 透明特效原轨道、短片、确定性构建、对象续签、固定50条与排他锁；上传中断不重复；审核受理即时落盘、旧终态与线上冲突门禁。
- test_progress.py: 进度阶段与下一条命令、在途时提示 poll 存活、demo 门、三种交付来源（state、pack、收据）、逐条驳回原因、status 走新入口。
- test_voice_policy.py: 平台音色与语速保留；日常、QC、续产与补齐不筛音色或性别；保护音量、画面与文案门禁，不依赖音轨返工工具。
- test_skill_budget.py: 常驻文本上限：SKILL.md ≤ 7000 字符；产品 rules 不混 AIGC 外貌规则。
- CLAUDE.md: 测试目录地图。

[PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md

- test_quality_contract.py: 真实多样性、单片统一与片内去重离线回归。
- test_sync_skill.py: 真实 Git 源验证连续原地更新；不生成备份包，保留文件指纹与本地改动门禁。

- test_group_rework.py: 保留原开场/整篇口播与字幕、禁用及重复源、覆盖/时长、单行与CTA音效箭头对齐；原生封面元数据及等价数值规范化。

- test_task_configuration.py: 新批次配置必须绑定已审文案与真实切片ID；明确待生成AI，不把计划池当已存在，不放宽人审门。

- test_demo_authorization.py: 先做demo的明确许可、单条AI绑定、改稿/改标签失效及量产仍需客户demo批准。

- test_caption_semantics.py: “洗个头 / 发丝”真实字幕边界保护，阻止跨句词错分。

- test_checked_batch_authorization.py: 条件生产许可绑定当前demo/文案/AI标签和7类实际证据，拒绝过期或扩大范围。
- test_font_variation.py: 字体候选与真实字体家族计数独立于字幕配色样式。

- test_task_caption_repair.py: 保留真实词级配音、整词字幕、绑定源窗证据；原生主画面构图只改指定镜头，拒绝来源证据篡改、非有限值和露边。
