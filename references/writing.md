# 写底稿：照团队的写法写

2026-11-05 用户定：脚本 Agent 自己写，不让平台写、不写 creative plan。写法照「Y26-联合利华脚本合集」里团队交付过的稿（清扬 0908~1104、清扬-DC、力士 1.0）。

```bash
python3 -I scripts/brief_card.py --config $C --run $R              # 当天每个 brief 一张任务卡
python3 -I scripts/brief_card.py --config $C --run $R --brief <id> # 只看一个
```

任务卡列出写这一条要的全部东西：排期这一行、骨架、卖点和机制的固定说法、产品要求、素材画面、禁用词、平台提示词 `video_script_create` 里的文案规则、同产品同方向的范本和团队交付过的稿、审核人改过的句子、已经用过的开头。照卡写，写完填进 brief 的 `segments`。

## 1. 排期这一行就是任务

店铺/产品 × 内容方向 × 测试卖点 × 人群。**方向和人群决定开头，测试卖点决定中间讲什么。** 方向括号里的字（如「法国人头发发质蓬松溯源」）和人群（「新锐白领」）是标签，不念出来。

## 2. 骨架：5~6 句，每句一个任务

| 句 | 任务 | 团队稿的例子 | 每条要新写吗 |
|---|---|---|---|
| ① 开头 | 戳一个头发状态，或给一个让人停下的说法 | 「头盔一摘，发根贴着头皮」「谁懂啊，在超市货架前只拿了一瓶，结果拍一发四」 | **要**，跟方向和人群走 |
| ② 引产品 | 一句话带出产品全名 | 「可以试试这瓶清扬控油蓬松洗发水」 | 换个说法就行 |
| ③ 卖点 | 测试卖点，说它做了什么 | 「SCA控油蓬松技术，洗完发根清爽蓬松」 | 用 config 的 `say`，可以复用 |
| ④ 效果 | 洗完 / 用完看得见、摸得到的结果 | 「洗完干干净净，发根直接立起来，不贴头皮」 | 可以复用 |
| ⑤ 机制 + CTA | 双十一 + 机制 + 戳直播间 | 「双十一快戳直播间带几瓶回去试试，89.9元拍一发四，想多囤点就拍二发八」 | 可以复用 |

- **开头不报机制**（用户 11-06）：价格优惠、爆款复刻方向也一样，机制只放最后一句。价格优惠方向的「优惠」体现在结尾机制句的语气里（「囤着不心疼」「一次囤够」）
- 团队 1029、1102 的稿里，③④⑤ 几乎一字不差地用在不同 brief 上，真正每条不同的是 ①（有时连 ②）。lint 也只查开头

## 3. 开头怎么跟方向走

| 方向 / 人群 | 团队写的开头 |
|---|---|
| 大促方向：货架、超市 | 超市选洗发水，只拿了一瓶，结果拍一发四 |
| 追根溯源 · 小镇青年 | 天天埋头干活，闷热出汗，下班头发油塌 |
| AI 单人口播 · 都市蓝领 | 骑摩托，头盔一摘头发油塌 |
| 双人演绎 | 周末赶集，头发没一会儿就扁塌 |
| 双十一 | 双十一蹲快递站等包裹，包裹没来头发先塌了 |
| 价格优惠 / 爆款复刻 | 同样从头发状态开头（「头盔一摘，发根全贴在头皮上」），机制留到结尾 |
| 品牌背书、成分种草 | 懂头皮护理的都知道，控油洗发水拼的是技术和配方 |
| 力士 · 日常 | 出门前整理发型，你会在意哪些细节？ / 柔顺，是发丝流动的美感 |
| 力士小香瓶 | 来不及重新打理头发怎么办？ / 别再只补妆不补香 |

**开头只写人和头发状态**（用户 11-06）：第一句要让观众认出自己的头发（发根贴头皮、头顶塌、一摸一手油、发缝明显、发尾毛躁打结），可以带一句场景或热梗当引子。不用这些开头：价格、机制、套组；瓶背、成分表、配方、技术名词释义（「净澈这个词…」）；瓶身、泵头、包装外观；「先别急着…」「你的清单想好了吗」这类绕弯子的问句。lint 会拦第一句里的价格、机制、瓶背、成分表。

**场景只点一句，马上落到头发状态。** 素材库里没有超市、仓库、摩托、快递站的画面（见产品 config 的 `footage`），场景词只做引子，画面接得住的是头发：发根贴头皮、头顶塌、一摸一手油、发缝明显、发尾毛躁。不写「女朋友安利」「老公」这类女生视角（清扬 2X / 呼吸瓶配音是男声）。

同一天同方向的几条，开头要各不相同（任务卡会列今天已经用过的开头）。**换的是开头的类型，不只是换个头发状态**（用户 11-06：力士 8 条开头都是「发尾毛躁 / 打结 / 碎发」，觉得重复）。同一产品当天的几条，从下面轮着选，同一类型最多用两次：

| 开头类型 | 例子 |
|---|---|
| 反问 | 洗完头一吹干，怎么还是毛毛的？ |
| 给一个判断 | 选洗发水，别只看洗得干不干净。 |
| 一句氛围 / 金句 | 好看的披发，靠的是发丝那点光泽。 |
| 场景引子（穿搭、拍照、出门前、包里） | 秋冬穿搭配好了，头发却拖了后腿。 |
| 香味 / 感官 | 头发香不香，一撩就知道。 |
| 跟观众对话 | 出门前照镜子，你先看妆还是先看头发？ |
| 热梗 | 头发香香顺顺的，就是给自己的情绪价值。 |
| 直接戳头发状态 | 梳子梳到一半卡住，发尾又打结了。 |

不管哪种类型，第二句都要落到头发状态，画面接得住。

## 4. 每句写 2~3 个说法

团队稿每句都给 2~3 个版本，三种语气各一：

- 口语带情绪：「我直接原地表演一个『赚麻了』」
- 正常叙述：「超市里精挑细选，只拿了一瓶，结果拍一发四」
- 偏书面：「双十一期间可进直播间选购」

主版写在 `text`，另外 1~2 个写在 `alt`（列表）。审核人在待审文档里挑或改（「备选：A / B」）。提交时审过的说法会写进这条脚本的改写要求，平台改写时在这个范围内换措辞。每个说法 lint 都查。

## 5. 硬性要求（lint 会查，错了必须改）

- 产品全名完整出现（不被标点、空格拆开）；尽量第 3 段才出现（提醒）；第一次讲卖点那句带产品名，不用「这瓶」「这款」代替（报错）
- 测试卖点出现；机制只用 config 里的；结尾有「戳直播间」或「进直播间」（用户 11-06：一个意思）；双十一期间带「双十一」
- 品牌禁用词、产品 `warn_words`、时间承诺（72 小时、3 天、7 天）、极限词、别的产品的卖点
- 一个短句一条字幕：≤ 20 字（超过报错），建议 ≤ 12 字；整条 75~150 字
- 平台提示词：每段 10~30 字；只写正向描述（「同事说我最近闻起来很清爽」，不写「头发不臭了」）
- 开头不报机制、不讲瓶背成分表：第一句出现价格、机制、套组、瓶背、成分表、配方表，报错
- 开头不撞：开头两句和范本 / 近 7 天同产品 / 当天其它稿相似度 > 50%，或同一天第一句开头 4 个字一样，报错

lint 不查文风。

## 6. 提示框里的规矩（脚本合集）

- 结尾说「戳直播间」；重命名时结尾加上内容方向；一个 brief 一个脚本
- 卡审词：头皮闷堵（不要太详细地描述头皮问题）、修护、修复、原价、拉满、性价比、源头、根源、最、第一、xx 级、国际
- 不写具体时间，改成「清爽感持续很久」
- 画面：不要掉头屑的 AI 素材、明星脸、白大褂，发缝不要太宽
- 力士：每个 brief 标好颜色（全 SKU / 紫 / 粉 / 绿 / 白），按颜色找之前的稿；结尾引导直播间下单

## 7. 待审

待审文档每条写出开头最像的旧稿和相似度。审核人改过的句子记进 `learned/`，下次任务卡会列出来。用户说好的整条脚本加进 `gold/` 标 `confirmed`，写上 `direction`，任务卡按方向找范本。

## 8. 热梗（用户要的时候才加）

用户说「结合热点」时，写稿前查热梗，写进 `$R/hotspots.json`，每个梗指定用在哪几个 brief，任务卡会列出来：

```json
[{"topic": "不烧心", "since": "2026-10", "meaning": "夸东西靠谱、用着省心",
  "source": "新华网 2026-10-20、大众网 2026-10-15", "url": "https://…", "briefs": ["1105-B01"]}]
```

**来源（用户 11-05 定）**

| 能用 | 用来判断什么 |
|---|---|
| 抖音热点宝 / 巨量算数（用户导出或截图给） | 真实热度，最准 |
| 抖音官方热点榜、第三方热榜聚合（豚榜、今日看等） | 当天在火什么话题 |
| 新闻报道（新华网、人民网、南方周末、澎湃、央视网等） | 梗已经出圈、意思和出处 |
| 《咬文嚼字》等年度流行语榜 | 老梗还在用，大家都懂 |

**不用梗百科（geng8.com）**：它的榜只算站内搜索，一天几百次，说明不了火不火。

**怎么挑**

- 每个梗至少有一个上面的来源，写进 `source` 和 `url`；只在梗词典里查得到的不用
- 写清 `since`（什么时候火的），老梗可以用，但不说成「这几天最火」
- 能一句话转到头发状态的才用；热榜上的新闻、话题标题（「北京周末有雨雪」「男生秋冬简约穿搭攻略」）不念进口播
- 不挑：灾难事故、社会负面、政治、明星个人和绯闻、别的品牌、需要具体数据才成立的
- 一个 brief 最多一个梗，只放开头一句；找不到够格的就不加，照第 3 节写开头

## 附：brief 格式

`parse_schedule.py` 生成空壳，Agent 填 `segments`：

```json
{
  "brief_id": "1105-B02", "product_key": "2x",
  "direction": "大促方向：货架、超市，丰富场景", "selling_point": "双重酰胺修护组合", "audience": "新锐白领", "quantity": 10,
  "segments": [
    {"id": "1", "role": "hook", "title": "开头", "text": "超市货架前挑半天，发根早就贴头皮了。",
     "alt": ["站在货架前选洗发水，一摸头顶全是油。", "选洗发水那会儿，头发已经油得贴头皮。"]},
    {"id": "5", "role": "cta", "title": "机制", "text": "双十一快戳直播间，89.9元拍一发四，想多囤就拍二发八。"}
  ]
}
```

**每句配什么画面（用户 11-09）**：平台建脚本时会给每段挑一个素材标签，但它常常对不上这句话（比如「头发也得保湿」配到了产品外观，「法式奢香」配到了只有 4 条的闻香味）。写完稿逐句对一遍：这句话该看到什么画面。对不上的，在分段里写 `visual_tags`（只能从产品 config 的 `footage_tags` 里挑，写两个任一命中，素材少的标签配一个素材多的兜底）。`submit` 建脚本时按它改，已建好的脚本用 `clipo_batch.sync_visuals` 改。常见对应：讲洗、保湿、泡沫 → 泡沫丰富 + 产品质地；说产品名 → 产品外观；讲香味 → 头发顺滑 + 闻香味；讲成分 → 产品质地。

`role`：`hook` / `pain` / `product` / `selling` / `effect` / `cta`，第一段 `hook`，最后一段 `cta`。每段都开 AI 改写（CTA 也改），改写后丢了机制或 CTA 词的视频按驳回处理。画面、贴图、音效由平台按提示词配，brief 里不写。
