# 写底稿：skill 出创作要求，平台写文案

平台的建脚本提示词（`video_script_create`）本来就会写文案、配包装。它不知道的是：今天排期要什么、这个产品踩过哪些坑、用户认可过哪些稿、最近几天写过什么、今天有什么热点。**skill 把这些写进创作要求（`requirement`），让平台写**；写出来的稿 lint 一遍、人审一遍，审过才生成。

```
查热点 → hotspots.json → draft.py（拼创作要求 → 平台写 → lint → 有错让平台改一轮）→ lint_copy.py → 人审
```

文案写得不对，按问题出在哪改：

| 问题 | 改哪里 |
|---|---|
| 这个产品的事实、禁用词、受众、素材画面、固定要求 | `config/<品牌>/<产品>.json`（`rules`、`audience_note`、`footage`、`warn_words`…），下次 `draft.py` 自动带上 |
| 口吻、长短、宽泛程度 | 用户说好的稿加进 `gold/<品牌>.json` 标 `confirmed`，`draft.py` 会塞进去当参考 |
| 平台每次都犯的写法问题（所有 skill、所有人都会遇到） | 告诉用户去改平台提示词 `video_script_create` |
| 某一条的个别句子 | 审核人在待审文档里直接改，改动记进 `learned/`，下次写进创作要求 |

## 1. 查热点

每天写稿前搜一次当天的热梗（抖音、微博、小红书等），核对传播时间和原本语境；通常挑 2~4 个，大批量脚本可以适当多挑，写进 `$R/hotspots.json`：

```json
[
  {"topic": "嘻嘻不嘻嘻", "source": "11.4 梗语访问榜",
   "url": "https://www.geng8.com/rank/day/2026-11-04/",
   "angle": "镜前看到油塌或梳子卡住的情绪反转", "products": ["2x", "jingyou"]},
  {"topic": "我要验牌", "source": "抖音开放平台梗语案例",
   "url": "https://developer.open-douyin.com/forum/bulletin/post/698d9852a9441abeb0d4c8e0",
   "angle": "翻瓶背看成分", "products": ["2x"]}
]
```

- 挑有辨识度的口头禅或反差句式，能一句话落到素材里的发根、发缝、发尾、瓶身；`angle` 写清怎么转到头发
- 普通热榜话题标题不等于热梗；不要把「秋冬简约穿搭攻略」这类标题直接念进口播，也不要硬贴不相干的梗（用户 2026-11-05 反馈）
- 不挑：灾难事故、社会负面、政治、明星个人和绯闻、别的品牌、需要具体数据才成立的
- `products` 写哪些产品能用；不写就是全部
- 用户给了热点或方向，照用户的写
- 没有合适的就不写这个文件，`draft.py` 不加热点
- 热梗只借表达方式做一句开头，素材里没有梗的专属画面，马上转到头发状态（见第 3 节）。站内访问榜只证明有人检索，不当作平台播放量

一个 brief 最多用一个热点，同产品的 brief 轮着用。

## 2. 让平台写

```bash
python3 -I scripts/draft.py --config $C --run $R --dry-run          # 只打印每个 brief 的创作要求，不调平台
python3 -I scripts/draft.py --config $C --run $R                    # 每个还没写的 brief 让平台写一条
python3 -I scripts/draft.py --config $C --run $R --brief <id> --redo  # 重写某一条（删掉平台上的旧脚本）
```

创作要求按这个顺序拼，最多 2000 字（平台上限）：

1. 任务：产品全名、段数、字数；用户给了结构（brief 的 `template`）就照结构分段
2. 排期：内容方向、测试卖点、人群、方向说明；卖点怎么说（config 的 `say`）
3. 机制和 CTA：只用 config 的机制，双十一期间带上；最后一段要有 CTA 词、不允许 AI 改写
4. 产品名规则：说全名、不用「这瓶」代替、尽量第 3 段才出现、第一次讲卖点那句带全名
5. 受众（`audience_note`）和这个产品的 `rules`
6. 素材里有什么画面（`footage`），不写素材接不住的场景
7. 不能写的词（品牌禁用词 + 产品 `warn_words`，去掉 `allow_words`）
8. 热点和怎么转到产品
9. 最近 7 天和当天别的稿用太多的开头，让它换
10. 审核人以前怎么改过（`learned/`）
11. 用户确认过的稿，塞到 2000 字为止，只学口吻和长短，不照抄

平台写完，`draft.py` 先把平台脚本按排期命名（config 的 `naming`，如 `1105-B01-清扬控油蓬松洗发水-双重酰胺修护组合-新锐白领-大促方向：货架、超市，丰富场景`；视频和分享页也用这个名字），再 lint；有错误（事实、合规、产品名、照抄），把错误列给平台改一轮（同一个接口带 `script_id`）。还有错就留给人改。写好的稿存进 brief：`script_id`（平台脚本）、`segments`（每段文案）、`requirement`（这次的创作要求）、`hotspot`。

## 3. 人审时看什么

lint 查得出的是硬性要求（第 4 节）。lint 查不出、人要看的：

- **每句都有画面接得住**：画面是按标签在产品切片里随机挑的，口播说什么，画面不会跟着找。痛点写头发本身的状态（发根贴头皮、头顶塌、一摸一手油、发缝明显），不写发生在哪（下班回家、坐沙发、工位、约会）。热点句只能有一句
- **像人说的话**：卖点说人话（「帮着管住头皮多余的油」），不堆形容词；一句一个意思；不喊口号、不排比
- **说话人对**：清扬 2X / 呼吸瓶是男生自己说或朋友安利（配音是男声）；二硫化硒、力士是女生口吻
- **结果具体**：不说「很蓬松」，说「手指插进发根能立起来」「侧头看头顶有空气感」
- **不是换汤不换药**：待审文档写了每条最像的旧稿和相似度

不满意的句子直接改；整条不行就 `--redo` 让平台重写，或者把问题写进产品的 `rules` 再重写。

## 4. 硬性要求（lint 会查）

- 产品全名完整出现（不被标点、空格拆开）；第一次讲卖点的那句带产品名（报错）；说到产品不用「这瓶」「这款」代替（报错）；产品名尽量不在前两段（提醒，照用户结构写时不查）
- 测试卖点出现；机制只用 config 里的；结尾有 CTA 词；双十一期间带「双十一」
- 品牌禁用词、时间承诺、极限词、机制以外的数字、别的产品的卖点（`foreign_claims`）
- 排期「内容方向」括号里的字、「测试人群」是标签，不进口播
- 断句就是排版：一个短句一条字幕，≤ 20 字（超过报错），建议 ≤ 12 字；整条 75~150 字
- **不照抄**（`lint_variety`）：去掉产品名、卖点术语、机制以后，跟范本 / 近 7 天同产品的稿 / 当天其它稿比，相似度超过 35% 报错；段落顺序一样且同位置 2 句以上开头一样报错（照用户结构写时不查这条）
- 具体场景词（`banned_words.scene_warn`）、说话人不对的词（`speaker_warn`）报提醒

lint 不查文风。

## 5. 用户给了结构

用户直接给一个结构（如「痛点问句 → 产品 + 机制 → 卖点 → 效果 → 人群 + CTA」）时，brief 里写 `template`，`draft.py` 会让平台照这个结构分段。用户给的例句里有的话也要守规矩：「2 倍立体蓬松」被平台 AI 审核判夸张驳回过、「长效维持」「持久控油」是时间承诺、「减少洗头频率」是功效承诺、「全家都能用」跟男士定位不符。

## 附：brief 格式

`parse_schedule.py` 生成空壳，`draft.py` 填 `script_id`、`segments`：

```json
{
  "brief_id": "1105-B01", "product_key": "2x",
  "direction": "大促方向：货架、超市，丰富场景", "direction_core": "大促方向", "direction_note": "",
  "selling_point": "双重酰胺修护组合", "audience": "新锐白领", "quantity": 10,
  "script_id": "6a…", "hotspot": "嘻嘻不嘻嘻", "requirement": "为「清扬控油蓬松洗发水」写…",
  "segments": [
    {"id": "1", "role": "hook", "title": "热梗开头", "text": "…"},
    {"id": "5", "role": "cta", "title": "引导下单", "text": "…"}
  ]
}
```

`role`（`hook` / `pain` / `product` / `selling` / `effect` / `cta`）按平台给的段标题猜，第一段 `hook`、最后一段 `cta`（不改写）。分段可选字段：`lock: true` 这段不改写、原样念；`alt` 备选句给审核人挑。画面、贴图、音效由平台配，brief 里不写。

## 附：清扬三个产品的要点

都适用：结尾「戳直播间」；产品名说全，口播不说「2X」（会念成「二艾克斯」）；卡审词：头皮闷堵、修护、修复、原价、拉满、性价比、源头、根源；不让 AI 仿真人第一人称「我用了之后…」；不写「齁」（平台审核当错别字）。

| | 控油蓬松洗发水 `2x` | 控油呼吸瓶 `huxi` | 二硫化硒蓝C瓶 `selenium` |
|---|---|---|---|
| 受众 / 口吻 | 男生，跟兄弟聊 | 男生 | **女生**，姐妹安利；不写「兄弟」 |
| 卖点 | SCA / 双重酰胺组合 / OCT（少提） | 按客户「DC-产品卖点」文档：去屑、长效清爽、10层深净澈、超微分子净屑科技 | 二硫化硒搭配清扬配方，头皮净澈舒爽 |
| 能写 / 不能写 | 不写头屑、长效、2 倍、全家共用 | **可以**写去屑、长效控油、香氛生花；不写源头、90% | 不写头屑、止痒；香味写淡淡清香 |
| 机制 | 89.9 元拍一发四 / 拍二发八 | 79.9 元到手 1500g，拍一发六 | 拍一发六，149.9 元 |

完整的在 `config/qingyang/<产品>.json`，力士在 `config/lux/<产品>.json`。
