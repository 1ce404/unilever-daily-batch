# 写底稿：照范本的标准写，不照范本的句子写

11.02 退了六稿：照规则拼出来的稿像 AI。11.03、11.04 又反过来：照 7 条确认稿逐句改，每天都是同一条视频换几个字，用户说「不能一直抄吧」。所以：

> **范本定标准（口吻、长短、能写什么不能写什么），每条脚本自己想角度、自己定句子。**

## 1. 看范本：学标准，不学句子

```bash
python3 -I scripts/imitate.py --config $C --run $R --brief <id>    # 列出确认稿、本品事实、每段素材里有什么画面、近几天已经用过的开头
```

范本库在 `gold/<brand>.json`：

1. **用户确认的**（`"status": "confirmed"`）：2026-11-03 确认了 11.02 那 7 条（`Y26-1102-B01`~`B07`）。从它们身上学的是**标准**：
   - 说的是头发本身的状态，不是某个场景
   - 男生自己说或朋友安利，像跟兄弟聊天
   - 每句都有素材画面接得住
   - 卖点说人话（「帮着管住头皮多余的油」），不堆形容词；一句一个意思，12~15 字一断
   - 不喊口号、不用排比、感叹号很少
2. 团队已交付的：看结构和接词有哪些可能；里面的具体场景素材接不住
3. 两条清扬千川实投：只借口吻

**用户说「这条好」的，加进范本库标 `confirmed`**。范本越多，标准越清楚，但不是越多句子可以抄。

## 2. 每条自己写，换角度不换词

一个 brief 先定**角度**，再写句子。同一天的几条、连着几天的稿，角度要轮换：

| 换什么 | 可以有哪些 |
|---|---|
| 开头怎么切入 | 直接说头发状态 / 问一句 / 给一个判断（「油头选洗发水别只看…」）/ 劝阻（「别再…」）/ 跟兄弟吐槽 / 品牌认知 |
| 段落顺序 | 痛点→产品→卖点→效果 / 先给产品再讲为什么 / 先讲卖点原理再给产品 / 痛点→原因→产品 / 产品和机制提前 |
| 句数 | 3~6 句都行，不用跟范本一样 |
| 接词 | 「后来」「别慌」「其实」「试试」「它里面的」都用过很多次了，少用 |
| 卖点怎么讲 | 讲它做了什么（管住油）/ 讲洗的时候的感受 / 讲洗完看得见的结果 |

**lint 会拦逐句改出来的稿**（`lint_variety`）：去掉产品名、卖点术语、机制以后，和任一范本、近 7 天同产品的稿、当天其它稿比：

- 文字相似度超过 35% 报错（`copy_limits.similar_max`）。标定：11.02 那 7 条彼此最高 32%，逐句改出来的 24~61%
- 段落顺序一样、而且同位置有 2 句以上开头一样，报错（比如都是「后来 / 挤一 / 它里…」）

待审文档会写出每条最像的那条旧稿和相似度，审核人一眼能看出是不是换汤不换药。

### 每句都要有画面接得住

画面是按标签在产品切片里随机挑的，**口播说什么，画面不会跟着找**。每个产品素材里有什么画面写在它的 `footage` 里（`imitate.py` 会列出来）。以 2X 为例：

| 段 | 素材里有的 |
|---|---|
| 钩子 / 痛点 | 男生对镜看头发、摸头顶；俯拍头顶发根贴头皮、发缝明显、发丝泛油 |
| 产品 | 手拿瓶子转着展示，男生在浴室举瓶对镜头 |
| 卖点 | 瓶背成分表，挤出青绿色膏体、倒进玻璃碗 |
| 效果 | 洗完抓头发、吹头发，发根立起来；手里搓泡沫、头上满是泡沫 |
| CTA | 四瓶组合摆在桌上 / 托盘 / 礼盒里 |

所以痛点写**头发本身的状态**（发根贴头皮、头顶塌、一摸一手油、发缝明显），不写**发生在哪**（下班回家、坐沙发、工位、约会、打球、凑近闻）。范本里的场景句改成头发状态：

| 范本（素材接不住） | 改成（画面接得住） |
|---|---|
| 约会全程不敢凑过去说话，一低头就怕… | 头发一油就贴头皮，一低头发缝全露出来 |
| 看着他一下班就抓头发 | 头发总是油塌塌地贴着头皮，摸一下就是一手油 |
| 早上吹好的头发，到公司坐下就贴头皮了？ | 早上吹好的头发，没多久就贴头皮了？ |

**说话人用男生自己或朋友安利**：配音池 6 个全是男声，「老公 / 男朋友 / 他说」这类女生视角会被男声念出来。两性方向写成「女生一眼就能看出来」「兄弟们」这种男生视角。

lint 会把具体场景词（`banned_words.scene_warn`）和女生视角词（`speaker_warn`）报成提醒。

## 2.5 用户给了结构时：照结构写，每段写两版

用户会直接给一个结构让我们照着写（11.04 给的这条）：

| 段 | 功能 | 用户给的两版 |
|---|---|---|
| 1 痛点问句 | 一句问出头发的状态，让人认出自己 | 天天洗头，可头皮还是出油快吗 / 是不是刚洗完头，没过几小时就扁塌贴头皮 |
| 2 产品 + 机制 | 产品全名出场，价格和拍一发四一起报 | 试试控油蓬松洗发水！89.9 元直接带走 4 瓶… / 控油蓬松洗发水活动价 89.9 元 4 瓶… |
| 3 卖点 | 一个卖点，说它对头皮做了什么 | 依托 SCA 控油蓬松技术，改善头皮油脂过剩问题 / 这款添加 SCA… |
| 4 效果 | 一个看得见的结果 | 带来 2 倍立体蓬松效果… / 实现 2 倍立体蓬松效果… |
| 5 人群 + CTA | 点名一类人 + 戳直播间 | 想要拥有高颅顶的朋友… / 想要减少洗头频率的朋友… |

照它写的时候：

- brief 里写 `template`（结构说明），每段 `text` 写主版、`alt` 写备选版；待审文档两版都给审核人，审核人挑或改
- 段落顺序按用户的来，lint 不再查「段落顺序 + 句首雷同」，但**文字相似度照查**：同结构不等于同句子
- 用户给的例句里有的话不能照用，要按我们的规则改：「2 倍立体蓬松」被平台 AI 审核判夸张驳回过、「长效维持」「持久控油」是时间承诺、「减少洗头频率」是功效承诺、「全家都能用」跟男士定位不符被驳回过、产品名要说全「清扬控油蓬松洗发水」
- 一份结构可以配不同卖点（SCA / 双重酰胺 / OCT），每个卖点换一个痛点，别五条都是「出油」

## 2.6 外部写法里能借的（11.04 用户给的 DeepSeek 策略文档）

能借的：

- **前半段像内容，后半段像种草**：开头讲人和状态，产品晚一点出来（和「产品名不在前两段」一致）
- **结果要具体**：不说「很蓬松」，说「手指插进发根能立起来」「侧头看头顶有空气感」「摘帽后发根不贴」
- **口播像男生真会说的话**，不像广告；卖点用场景语言说（「洗完发根是立起来的」），不直接念技术名堆在一起
- **结构模型**轮换用：痛点解决型（痛点→产品→使用→结果→套组）/ 囤货值感型（套组→反转→场景→结果）/ 测评对比型（提问→测试→前后→解释→套组）
- **字幕**：前 3 秒大字短句强痛点；中段每句 ≤ 12 字；结尾 CTA 停 2 秒
- **套组**：不强调低价，讲「量够、囤着用」

不能照搬的：

- 它的脚本都是**具体场景 + 具体人物**（叠穿镜子前、景区摘帽、桂花树下），那是给**实拍**用的。我们是从现有素材库随机抽画面，库里只有头发状态、产品、泡沫、洗后抓发、四瓶组合，这些场景画面接不住（见上「每句都要有画面接得住」）。等平台素材库有了这些场景镜头再写
- 它写的「穿深色外套也放心」「头屑」暗示 OCT 去屑功效，清扬 2X 这里不写头屑；「OCT抑屑因子」会卡审，少提
- 「我出门前会用」这种第一人称体验，AI 单人口播里不写

## 3. 硬性要求（lint 会查，错了必须改）

- 产品全名完整出现：清扬控油蓬松洗发水（不可被标点或空格拆开）
- **产品名尽量不在前两段出现**：前面先讲头发的状态，第 3 段起再出产品（lint 提醒）
- **第一次讲卖点的那句要带产品名**：「清扬控油蓬松洗发水用的是 SCA…」，不能只说「得找带 SCA 的」（lint 报错）
- 说到产品时说全名，不用「这瓶」「这款」「它」代替（lint 报错）
- 测试卖点出现；「双重酰胺修护组合」口播写「神经酰胺加烟酰胺，双重酰胺组合」（「修护」卡审）
- 机制只用 config 里的；结尾有「戳直播间」；双十一期间带「双十一」
- 不写头屑、头痒、掉发、时间承诺、极限词；不串别的产品的卖点
- 排期「内容方向」括号里的字（如「法国人头发发质蓬松溯源」）、「测试人群」都是标签，不写进口播
- **断句就是排版**：一个短句 = 一条字幕。短句 ≤ 20 字（超过报错），建议 ≤ 15 字；单独 1 个字的短句会提醒
- 整条 75~150 字（约 15~25 秒成片）
- **不照抄**：跟范本 / 近 7 天 / 当天其它稿相似度 ≤ 35%，段落顺序一样时同位置开头相同不超过 1 句（见第 2 节）
- `persona` 一句话写「身份 + 口吻 + 语速」（如「头发爱油的男生跟兄弟吐槽，口吻随意，语速中等」）；配音全是男声，不写女生视角

lint 不查文风。

## 4. 待审

待审文档每条写出最像的旧稿和相似度（超过 30% 标「偏高」）。审核人改过的句子记进 `learned/`，下次 `imitate.py` 会列出来。用户说好的整条脚本加进 `gold/` 标 `confirmed`。

## 附：brief 格式

`parse_schedule.py` 生成空壳，你补 `angle`、`persona`、`gold_id`、`segments`：

```json
{
  "brief_id": "1104-B03", "product_key": "2x",
  "direction": "痛点种草-双人演绎", "direction_core": "痛点种草-双人演绎", "direction_note": "",
  "selling_point": "SCA控油蓬松技术", "audience": "资深中产", "quantity": 10,
  "angle": "对兄弟发问，讲原因，再给产品和技术",
  "persona": "男生跟兄弟聊天，先问再解释，口吻随意",
  "gold_id": "Y26-1102-B06",
  "segments": [
    {"id": "1", "role": "hook", "title": "钩子", "text": "…"},
    {"id": "5", "role": "cta", "title": "CTA", "text": "…"}
  ]
}
```

`role`：`hook` / `pain` / `product` / `selling` / `effect` / `cta`，第一段 `hook`，最后一段 `cta`（不改写）。画面、贴图、音效由平台按提示词配，brief 里不写。分段可选字段：

| 字段 | 作用 |
|---|---|
| `lock` | `true` 时这段不改写、原样念 |
| `alt` | 备选句，给审核人挑（照用户结构写时用） |

## 附：清扬固定要求（QC 文档「清扬2x、控油呼吸瓶」和近期 callout）

三个产品都适用：

- 结尾说「戳直播间」（三个产品都是，二硫化硒 11.04 用户确认）
- 产品名说全，不用「这瓶」代替；口播不说「2X」（会被念成「二艾克斯」）
- 卡审词：头皮闷堵、修护、修复、原价、拉满、性价比、源头、根源；画面不要掉头屑的 AI 素材、明星脸
- AI 单人口播：不让 AI 仿真人第一人称「我用了之后头皮…」，写「推荐 / 安利」
- 不写「齁」，平台 AI 审核会当错别字驳回

**每个产品自己的要求在 `config/qingyang/<产品>.json` 的 `rules` 里**，`imitate.py` 写之前会列出来。要点：

| | 控油蓬松洗发水 `2x` | 控油呼吸瓶 `huxi` | 二硫化硒蓝C瓶 `selenium` |
|---|---|---|---|
| 受众 / 口吻 | 男生，跟兄弟聊 | 男生 | **女生**，姐妹安利；不写「兄弟」 |
| 卖点 | SCA / 双重酰胺组合 / OCT（少提） | 按客户「DC-产品卖点」文档：去屑、长效清爽、10层深净澈、超微分子净屑科技 | 二硫化硒搭配清扬配方，头皮净澈舒爽 |
| 能写 / 不能写 | 不写头屑、长效、2 倍、全家共用 | **可以**写去屑、长效控油、香氛生花；不写源头、90% | 不写头屑、止痒；香味写淡淡清香 |
| 机制 | 89.9 元拍一发四 / 拍二发八 | 79.9 元到手 1500g，拍一发六 | 拍一发六，149.9 元 |

2X 没有官方香型名：只写清爽、淡淡清香、干净的味道、不腻；不写留香时长，画面不用樱花、粉色。
