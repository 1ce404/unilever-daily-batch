# 写底稿：照团队的写法写

脚本 Agent 自己写，不让平台写。写法照「Y26-联合利华脚本合集」里团队交付过的稿。

```bash
python3 -I scripts/brief_card.py --config $C --run $R              # 当天每个 brief 一张任务卡
python3 -I scripts/brief_card.py --config $C --run $R --brief <id> # 只看一个
```

任务卡列出写这一条要的全部东西：排期这一行、骨架或结构、卖点和机制的说法、产品要求、素材画面、禁用词、卡审库指引、平台提示词里的文案规则、范本和团队交付过的稿、已经用过的开头。照卡写，写完填进 brief 的 `segments`。

**终稿必须照平台建脚本提示词 `video_script_create` 的文案规则写**（每段字数、禁用词、只写正向描述）。任务卡每次现读平台，读不到就停，不凭记忆写。产品配了卡审库（Cyber）时，lint 逐词拦，高风险词报错；写法看 `references/review-blocks/<库>-guide.md`。

## 1. 排期这一行就是任务

产品 × 内容方向 × 测试卖点 × 人群。**方向和人群决定开头，测试卖点决定中间讲什么。** 方向括号里的字和人群是标签，不念出来。

**有结构的排期**（AHC）：brief 的 `template` 写着这条的结构（例：「AI片头 + 产品种草 + 成分功效 + 上脸过程 + 好皮肤素材 + 价格福利 + 直播间引流」），按这个顺序分段，下面的通用骨架只作参考。结构定义在 `config/ahc.json` 的 `structures`。

## 2. 骨架：5~6 句，每句一个任务

| 句 | 任务 | 例子 | 每条要新写吗 |
|---|---|---|---|
| ① 开头 | 戳一个状态（头发 / 肌肤 / 衣物），或给一个让人停下的说法 | 「头盔一摘，发根贴着头皮」 | **要**，跟方向和人群走 |
| ② 引产品 | 一句话带出产品全名 | 「可以试试这瓶清扬控油蓬松洗发水」 | 换个说法就行 |
| ③ 卖点 | 测试卖点，说它做了什么 | 「SCA控油蓬松技术，洗完发根清爽蓬松」 | 用 config 的 `say`，可以复用 |
| ④ 效果 | 用完看得见、摸得到的结果 | 「洗完干干净净，发根直接立起来」 | 可以复用 |
| ⑤ 机制 + CTA | 机制 + 引导（直播间 / 小黄车 / 下方链接，看产品 `cta_required`） | 「快戳直播间，89.9元拍一发四」 | 可以复用 |

- 开头不报机制、价格、套组，不讲瓶背、成分表；机制只放最后一句。例外：爆款复刻可以机制开头，结构里写了机制开头的（AHC 结构6 / 9）照结构
- 卖点句、机制句可以跨 brief 复用，真正每条不同的是开头。lint 只查开头撞车

## 3. 开头怎么写

第一句让观众认出自己的状态（发根贴头皮、发尾毛躁、皮肤干到起皮、衣服洗完发硬），可以带一句场景或热梗当引子，第二句马上落到状态上。素材库里没有的场景（超市、仓库、摩托）只做引子，画面接得住的是状态本身。

同一天同产品的几条，开头类型要轮换，同一类型最多两次：

| 开头类型 | 例子 |
|---|---|
| 反问 | 洗完头一吹干，怎么还是毛毛的？ |
| 给一个判断 | 选洗发水，别只看洗得干不干净。 |
| 一句氛围 / 金句 | 好看的披发，靠的是发丝那点光泽。 |
| 场景引子 | 秋冬穿搭配好了，头发却拖了后腿。 |
| 香味 / 感官 | 头发香不香，一撩就知道。 |
| 跟观众对话 | 出门前照镜子，你先看妆还是先看头发？ |
| 热梗 | 头发香香顺顺的，就是给自己的情绪价值。 |
| 直接戳状态 | 梳子梳到一半卡住，发尾又打结了。 |

## 4. 每句写 2~3 个说法

主版写在 `text`，另外 1~2 个写在 `alt`，语气各一：口语带情绪 / 正常叙述 / 偏书面。审核人在待审文档里挑或改。提交时这些说法和禁用词写进这条脚本的改写要求，平台改写时在这个范围内换措辞。每个说法 lint 都查。

**改写会走样的地方**（改写要求里已写死，成片也会查）：
- 不加 `[#…]` 语音指令（一条视频几段语气差太多，听着像两个人）
- 产品出现后只讲好结果，不写「下班又干了」这类（像产品没用）
- 不写早上 / 下午 / 下班这类时间线

## 5. 硬性要求（lint 会查，错了必须改）

- 产品全名完整出现在一句里，不被标点拆开；尽量第 3 段才出现；第一次讲卖点那句带产品名，不用「这瓶」代替
- 测试卖点出现；机制只用 config 里的；结尾有产品要求的 CTA 词
- 品牌和产品禁用词、时间承诺、极限词、别的产品 / 香型的卖点（`foreign_claims`）、部分产品不写任何数字
- 一个短句 ≤ 20 字（超过报错），建议 ≤ 12 字；整条 75~150 字
- 只写正向描述（「同事说我最近闻起来很清爽」，不写「头发不臭了」）
- 开头两句和范本 / 近 7 天同产品 / 当天其它稿相似度 > 50%，或同一天第一句开头 4 个字一样，报错

lint 不查文风。各产品的具体要求在 config 的 `rules`，任务卡会列出来。

## 6. 每句配什么画面

平台按标签给每段挑素材，常常对不上这句话。写完逐句对一遍，对不上的在分段里写 `visual_tags`（只能从产品 config 的 `footage_tags` 里挑，写两个任一命中）。讲成分的那句配质地画面（config 的 `ingredient_footage`，没写 `visual_tags` 时自动配）。

**默认按标签随机选片**：每段写 `visual_tags`，平台从标签下全部素材中随机选取。不为去重缩小候选，不自动固定单条或创建素材池。只有用户明确指定素材时，才写 `visual_query`、无口播段的 `footage` 或逐条素材绑定；用户明确要求限定候选时才写 `footage_pool`。

**开头切片允许重复**，无需重复授权。不要求素材数匹配交付条数，不因重复补素材、自动换开头或拦交付。开头文案差异、素材合规与画面匹配仍检查。

限定素材池时，平台在 `tags` 范围里把相似度 ≥ `score` 的素材当候选，随机选片；`query` 写候选素材的共同点。用户指定单条开头时可用 `--size 1`、`visual_query`，或无口播段的 `footage`。
```bash
python3 -I scripts/clipo_batch.py pool --config $C --run $R --product <key> --tags <标签> --query "<共同点>" --size 5 [--allow-risk] --brief <id> --seg <段 id>
```
它取前 `--size` 条合格素材，把 `score` 设在池内外之间，写入该段的 `footage_pool`（写进去要重新给人审）。排在前面的有风险或禁用画面就停，提示换 query；AI 真人场景素材平台都标了风险，确认要用加 `--allow-risk`。开头素材池至少 1 条，仍须填写 query、tags、score。非开头段保留至少 3 条的素材池规则；固定单条的非开头段保留 `pack` 例外。交付按视频编号选取合格成片。

**无口播的原片开头**：第一段写 `{"id": "1", "role": "hook", "silent": true, "text": ""}`，再用 `pool` 配素材池，口播从第二段接着这个画面往下说。原片烧进去的字会被 AI 审核当成字幕来审，优先挑画面字干净的。

**按开头拆小 brief**：用户要求分配不同开头时，可以按开头拆小 brief（例：40 条分 6 个开头，拆成 7/7/7/7/6/6），每个写 `"pack": true`，交付时合成 10 条一个链接。默认无需为重复开头拆稿。

人物 AIGC（双人演绎、单条三镜同一个人）见 [aigc-production.md](aigc-production.md)。

## 7. 热梗（用户要的时候才加）

用户说「结合热点」时，写稿前查热梗，写进 `$R/hotspots.json`，每个梗指定用在哪几个 brief，任务卡会列出来：

```json
[{"topic": "不烧心", "since": "2026-10", "meaning": "夸东西靠谱、用着省心",
  "source": "新华网 2026-10-20", "url": "https://…", "briefs": ["1105-B01"]}]
```

- 来源用抖音热点宝 / 巨量算数、抖音热点榜、新闻报道、年度流行语榜；**不用梗百科**（站内搜索量说明不了火不火）
- 能一句话转到产品相关状态的才用；不挑灾难事故、社会负面、政治、明星绯闻、别的品牌
- 一个 brief 最多一个梗，只放开头一句；找不到够格的就不加

## 8. 用户认可的稿

用户说好的整条脚本加进 `gold/<品牌>.json` 标 `confirmed`，写上 `product` 和 `direction`，任务卡按产品和方向找范本。

## 附：brief 格式

`parse_schedule.py` 生成空壳，Agent 填 `segments`：

```json
{
  "brief_id": "1105-B02", "product_key": "2x", "direction": "大促方向：货架、超市", "selling_point": "双重酰胺修护组合",
  "audience": "新锐白领", "quantity": 10,
  "segments": [
    {"id": "1", "role": "hook", "title": "开头", "text": "超市货架前挑半天，发根早就贴头皮了。",
     "alt": ["站在货架前选洗发水，一摸头顶全是油。"], "visual_tags": ["头皮出油"]},
    {"id": "5", "role": "cta", "title": "机制", "text": "快戳直播间，89.9元拍一发四，想多囤就拍二发八。"}
  ]
}
```

`role`：`hook` / `pain` / `product` / `selling` / `effect` / `cta`，第一段 `hook`，最后一段 `cta`。每段都开 AI 改写（CTA 也改）。画面、贴图、音效由平台按提示词配。
