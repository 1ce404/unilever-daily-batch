# LUX 批量制作与自查（用户 2026-11-25）

阈值唯一来源是 `config/quality/lux.json`。本文件解释执行方式；新一轮明确要求可覆盖任务参数，须记录原话。

- **单片统一、批量多样**：一条片子的原生主字幕字体、字号、位置、描边、底纹保持统一。跨成片轮换原生样式、BGM、合适音色、人物和包装。不能把“统一原生字幕”理解成整批只选一种样式。不得把音色候选压成仅1–2个；不恢复全品牌本地黑白名单，默认仍沿用各产品平台提示词，用户明确指示才在任务级选配。
- **配置必须真的落到Clipo**：字幕 `config.subtitle_style.style_ids`、BGM `config.bgm.props.ids`、各段 `visual.props.segment_ids`、上方花字 `segment.effect` 均须备份、写入、回读。验收页有样片不等于系统素材池已绑定。把回读数量和实际输出采用情况分别记录；禁止依赖“看起来已设置”的本地计划。
- **素材池按语义和供给选量**：最低门槛不是默认统一数量，不把每段机械锁成12条。产品外观、质地、发质、CTA按相关性和人物/来源差异分别扩充；稀缺素材（如真实泡沫仅10条）明示实际数量，不能塞不对位镜头凑数。用户要求更多音色时任务级现场扩充品牌适配候选，不用平台原3个名单当上限；一条内音色与语速仍稳定。贴纸不只配结尾箭头，按开场/产品/卖点的功能分布，在非人物段选恰当原生效果并查实际避让。
- **素材池支持批量**：demo的两条固定片段不能沿用于10条批次。每个实拍段选足够多的合格候选，头发展示分散人物/造型。逐段分池；按规范化来源路径去重，不仅按segment ID去重，禁止 `% len(pool)` 循环补满一条视频。池不足就拦住，不默默回放同一动作。
- **跨片频率复核**：除片内去重，还要统计实际主画面每个规范化源的出镜条数、次数和秒数；同造型/同机位也要看图复核。用户明确否定的高频源写入对应品牌禁用表，连派生切片一起排除，不把同一人不同切片当作多个人，也不以另一条高频源机械替换。
- **结尾引导**：用户要求箭头与短音效时，两者都必须进入原生配置和实际成片，对齐本条CTA口播。抖音“戳直播间”指向右侧带直播标识的账号头像，不能指向瓶子、任意留白或左下角。使用Clipo“戳直播间头像-箭头”原生整张透明画布时，按产品平台提示词保留center、x/y=0、scale=1、rotation=0；先查看箭头实际方向和落点，不能因透明区域大就重算可见区域中心搬走箭头。若与产品冲突，应换合适的结尾画面构图，不能移离入口。其他平台入口按其已审要求，不套抖音坐标。检查实际可见区域、方向、首帧及CTA持续时间；不只检查贴纸是否存在。
- **AI钩子**：同类型画面至少达到用户要求的数量，并全部绑定该段真实素材池。原稿加备选的总数、标签、ID、批准记录都要可追溯；只绑定一条而展示五条不算完成。用户要求5个钩子轮换时跨片可按已说明的轮换方案使用，片内不得重复；未获批准的新素材不代替批准画面。
- **字幕美观**：主字幕单行；不让一个字符掉到第二行。按词级时间轴在语义边界切短句，保持全片样式统一，不靠逐句改字号凑宽。上方花字同样必须单行，不能把最后一字掉到第二行；缩成忠实短关键词或适当调字号/宽度，完整口播与主字幕不删。每处花字抽25%/50%/75%进度的真实渲染帧，人工检查自动折行及遮挡；仅配置无换行符不算通过。上方花字独立、克制，不能压住脸、发顶或产品。用户明确要求产品名和成分高亮时，在原生主字幕短cue中以不同颜色强调产品全名、天然鲜花精油和4D玻尿酸；单片字体、字号、位置、描边保持一致。黑字白边底样式用较深金/玫瑰色，白字深边样式用亮金/浅玫瑰色，检查对比度。高亮必须写进实际TextClip并回读，不只写计划。产品名/卖点可高亮；接口只支持整cue字色时如实说明，不能假称实现了同句逐字混色。原生 `safeTop` / `safeBottom` 是比例，不能写像素值。用户否定的自制花字不得复活。人物/头发特写铺满上方时，应把该花字移到有留白的产品画面，不在发顶硬压字；长卖点花字可用忠实的简短关键词，但口播和主字幕保留完整名称，实际渲染须查末字掉行。
- **声音有网感且贴品牌**：整篇一次合成，再按真实词级时间轴配字幕与镜头；一条内不换朗读人、不逐段忽快忽慢。默认速度见配置，已经单独批准的速度保留。BGM选择真正进入节奏的片段、多首轮换；音效与BGM分轨，动作、转场与卖点适量点缀，不盖口播、不爆音。用户说“声音好小”指音量，不得误读为音色不好或擅换朗读人。只改口播音量时，保留原配音源、音色、1.4倍或已批准语速、文案和词级时间轴，不重新TTS。Clipo原生音量字段上限为1；已到上限时，按skill的gain命令对同一条原音频做有峰值余量的线性增益、回传Clipo，再以原时间轴渲染。保留原文件哈希和增益收据，并检查最终混音峰值；不得把滑杆写成大于1或靠换声音解决音量。
- **用户BGM参考优先**：用户给了参考文档且说明已上传Clipo时，先读取参考内容，按该批用途定位曲类，再用名称和实际媒体文件对应Clipo资源ID；文档标题或类别名不能代替读曲目。快消节奏参考不能机械换成治愈/清新/氛围池；这是该批选曲要求，不扩成所有品牌禁用。父脚本配置明确ID池并回读；统计成片实际采用的曲目，而不是只数候选。取实测有效且进入节奏的源区间，保护原声对白，非对白开场不能沿用对白过度压低配乐。只改BGM时锁定其他全轨、字幕、箭头、音效、时间轴及已批准无转场状态。混音必须检查实际对齐的波形与渲染峰值，不把不同时刻的各轨峰值简单相加，导致音乐几乎听不到；声压/RMS只作筛查，不能冒充听感、BPM或实际节拍验证。仅改音频且所有解码视频帧哈希完全一致时可沿用前版实际视觉检查并明确留证；客户听感验收与技术通过分开记录。本次清扬参考返工由 `group_bgm_rework.py` 留对应表、精确曲库ID、有效源区间、混音检测与只改配乐的草稿差异证据，流程为 inventory → samples → plan → prepare → level_fix --dry-run → level_fix → group_rework_apply apply --dry-run/实际 → status/review → media → activate → finish；不得跳过渲染前混音门禁。
- **包装与结构**：上方花字须单独检查跨片差异，不能以主字幕样式数、BGM数或仅换字色代替。任务brief用`upper_title_variation.min_actual_sets`记录所需花字组合数，`batch_issues`按实际成片花字源码签名核对，再实际看图确认外观差异与人物避让。上方花字、贴纸、BGM、SFX、转场均应使用Clipo真实能力并进入配置；各组按脚本功能设计，避免套同一结构、同一个女生展示。痛点结构按已审脚本执行。不要为补变化加入不合品牌的字板或遮挡。
- **坏帧必须剪掉**：质地/泡沫/喷雾动作只保留已经真实出液、泡沫成形或雾化可见的高光区间；倒瓶对空盘、未出液或未出雾的准备等待段不得使用。实际看过的区间写进任务`source_highlight_windows`，后续同源落在区间外由QC拦住，不能只凭标签判定动作已发生。空镜拖长、产品出画后的尾巴、抖动与黑屏都不能混入；先实测源时长和安全区间，再选切点，不能慢放/循环补长。转场不能露黑底。黑帧检测须覆盖单帧，30fps下约33毫秒不能被35毫秒最短时长过滤掉；切点需看切前/切点/切后逐帧画面。用户明确要求某批删除转场时，只清空该批原生转场及对应脚本配置，保留花字动画、贴纸、主字幕和声音，不扩成所有项目永久禁用转场。逐片源路径去重、镜头覆盖/时长、词级同步、单行样式与真实多样性由机器检查；渲染后跑 `media_qc.py` 检查黑帧/峰值并输出逐镜头检查图，对空镜、抖动、脸/头发/产品遮挡进行实际看图/看片复核，记录证据。不能把“未检”写成“已通过”。

`quality_contract.py audit` 回读配置；`qc.py` 检查草稿与整组差异；`media_qc.py` 检查本轮渲染并留检查图。检查未完成或失败的片不进交付链接。自动审核与用户确认分开记录；AI误把上方花字当第二行字幕时保留原结论，只能按客户已批准的具体版式处理，不能通用忽略所有驳回。

终审局部返工保留已审文案、配音和时间轴，按问题镜头清单替换，不整批重生。提交前验证所有实际媒体地址可读取，失效音效换成当前Clipo资源而不是删除；dry-run与写回均比对完整草稿，仅允许同一OSS媒体对象临时签名续期。每轮返工有独立幂等凭据，完成后重检变动成片。

## 参考片驱动脚本（用户2026-11-25补充）

- 先拆原片的开场、问题/异议、购买理由、实拍动作和收口，再写新稿。记录时间点，区分画面可见内容、字幕与实际识别到的口播；识别漏段不冒充已核准的逐字稿。参考里的价格赠品、年限背书和科技功效仍属于原产品，须按本轮LUX资料重新核实，不因用户认可参考就跨品牌移植。
- 每句明确增加什么理由、让什么动作承接：按压、出料、手指顺发、喷口雾化、实物陈列等。成分句用真实质地，产品名用真实外观。连续演示可保留同一人物/同一场景，动作须递进；保留完整动作，再按语义切点剪，不能为凑素材多样性机械地每句换人。相同窗口重复和跨片高频造型仍要拦。
- 花字、重复字、勾选、划线、撒花与短音效围绕台词、动作或新增理由触发，写进逐句执行稿；只轮换模板ID或固定三个时段挂标签，不能代替脚本推进与节奏。原生主字幕仍单片统一、单行；包装差异另检。
- 先查Clipo现有资源的实际可配置字段和预览；名字相近不能证明功能等效。带硬编码评价、回购数字、赠品、价格或承诺的近似模板，不能直接套到LUX。用`reference_study.py inventory --config lux --run <本批目录>`只读盘点，再按具体缺项补资源。
- 用户明确指定另一聊天协作时，给出原片路径、准确时间范围、包装作用、品牌色与避让要求，以及需要的透明文件/工程。要求现成资源与自制备选分别标注，交付预览和真实文件；聊天已收到需求、只有预览、文件已取得、已绑定Clipo和成片已采用是不同状态，不能混报。


## 脚本连贯与收藏协作复核（用户2026-11-26补充）

- **先读成一段，再谈包装**：逐组完整读口播，检查相邻句的承接、指代和信息增量。开场抛出的具体疑问应由紧接的产品形态、卖点或动作回答；不要先造红毯、谜语或奇观，再用“先放一边”“路线”“精致”等泛词硬转。去掉画面、花字和音效，文案仍要通顺；增加转折词不等于因果成立。
- **一条主线持续展开**：同一触感、香气、洗感或具体困扰可以用动作和真实理由逐层推进，不必每两句另造问答或比喻。愿望说一遍即可，随后产品、护理依据和动作应增加信息。批量差异可来自感官起点、叙述顺序和动作，不用把同一通用正文套在五种抽象开头后面。
- **AI开头当场回收**：AI钩子与下一句必须围绕同一件事，例如喷雾形态对应“一喷化雾”，香氛产品视觉对应已确认的法式奢香定位。纯装饰动画不是实测；不生成与真实素材脱节的使用演示，也不让“开花”暗示未确认植物成分。AI数量、脚本人审和素材人审仍按本批要求执行。
- **用户收藏是具体证据**：用户明确授权跨聊天互相布置任务时，先交换收藏来源、原片文件与准确时段，再互相挑稿、分派素材核验；主会话保持本批唯一写入。实际拿到并看过的视频、仅有音轨、字幕核对与ASR底稿分别标明。协作收到任务不等于学完，建议提出不等于已落实；正式改稿前回看证据并记录采用或否决原因。
- **网感不冒充新热点**：用户认为过时的热梗立即退出当前稿。年度流行语、旧报道、梗词典站内访问量和搜索摘要不能证明今天新鲜；采用具体热点需留真实发布日期、内容来源、与产品一两句内的衔接。没有适配的新热点时，用原创口语、感官细节和真实动作，不给常用表达贴“最新热点”标签。
- **镜头承诺先核实**：按压泵头、喷出细雾、喷向发丝、湿发吹干是不同动作；标签和检索描述只作线索，实际看图/看片后才写可用。未找到的动作不靠文案、AI或包装假装存在。没有直接用法镜头时可用真实产品与用法信息条，如实注明。

形态疑问可由紧接的一句完整产品名与形态说明回答；这类短疑问不是无归属功效断言。机器检查只接受首段明确问用法、下一产品段马上回答的窄场景，其他卖点、禁词和事实闸门照常执行。

## 批量文案与人物供给（用户2026-11-26）

批量须有逐条实际文案变化，不是同一正文换音色、画面或包装。已审稿约束主线、产品名/成分/卖点事实，不等于禁止平台分段改写。改写保持前后指代、语气和CTA衔接，先读成整段；整篇TTS必须使用该条实际改写文案及对应词级时间轴，禁止覆盖回共同母稿。保存并比较每条成片主字幕拼合文案；精确重复在部分交付也拦住，仅换标点不算变化。

原生字幕即使单行，也不能在“忍不/住了”等词组中机械截断，或把产品名后的“泡”等下一句首字粘到名称cue。本次新批量用`task_caption_repair.py --production-skill <原快照> --plan <明确keys的清单> --dry-run`检查，再去掉dry-run做同cut局部重渲；复用已生成整篇配音及真实词级时间轴，不新增TTS、不换画面/包装、不改运行中的原生产快照。新修复命令有独立版本、预算、完整回读和幂等收据；重渲后旧视觉凭据不沿用。未经证实的比较文案先拦下，不能为赶时间默默放行或自动追加收费改写。

用户批准了具体新稿及单条重配次数时，用`task_variant_repair.py --production-skill <原快照> --plan <该条清单> --dry-run`核对1次整篇TTS、原音色/语速与原cut，再执行。单独的revision目录保留新旧配音收据；`task_bulk copies`按实际修订后的文案与用料统计，不把客户确认的新稿继续标为平台原始改写。

机器切句仍可能拆开“法式奢香”“一样不少”等词组。读完全部实际cue后，可在字幕修复计划的`caption_chunks`为问题视频列出完整短句；拼合全文必须相同，切点必须来自原生词级时间轴。`rereview --video-key <新视频编号>`只复审明确条目，默认跳过客户退回旧片。CTA须实际检查原生箭头与产品的相对位置；不能只凭“头像箭头”的名称通过。源替换后实际来源统计随独立修订证据更新；只按清单删除造成露黑的main转场，不动字幕、声音或其他包装。

用户明确批准某条AI试样并要求先出1条demo时，首次submit仅可用任务`approved_ai_hook_ids`精确一致的首段ID制作该demo；这不代表已满足量产5条AI池。存在原生成任务或demo审核后，提交审计仍按完整池门槛执行。`task_remove_black_reveal_transitions`只记录本批实际确认露黑的进场类型，供新demo精修清除，不全局删除其他项目转场。

选片不能只做片内去重或以不同切片ID当不同人物。先实看候选，归并同人物/造型/场景，制作整组分配，再按已用次数平衡选择；取消优先沿用平台旧选片造成的偏置。统计每位可辨人物组、每个源的出镜视频数/镜头数/秒数，供给不足明确指出，不把55个切片说成55个人。用户退回的批次须从可交付状态及当天交付分组撤出，保留原文件和退回证据，不通过复审清掉客户返工标记。
